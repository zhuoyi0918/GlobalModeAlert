# GlobalModeAlert · 代理模式提醒

Shadowrocket（小火箭）模块：定时检测当前是否处于 **全局** 或 **直连** 模式，忘记切回「配置」模式时发通知提醒。

## 原理

小火箭不向脚本暴露当前的路由模式，所以模块用两个"探针"从行为上判断：

| 探针 | 地址 | 模块规则 |
|---|---|---|
| A | `https://myip.ipip.net/json` | `DIRECT` |
| B | `https://www.cloudflare.com/cdn-cgi/trace` | `PROXY` |

全局 / 直连模式下分流规则会被忽略，探针的出口就会"走错路"：

| 当前模式 | 探针 A 出口 | 探针 B 出口 | 结果 |
|---|---|---|---|
| 配置 | 中国 | 境外 | ✅ 正常，不提醒 |
| 全局 | **境外** | 境外 | ⚠️ 提醒「全局代理还开着」 |
| 直连 | 中国 | **中国** | ⚠️ 提醒「当前是直连模式」 |

## 安装

小火箭 → 配置 → 模块 → 右上角 `+` → 粘贴以下链接：

```
https://raw.githubusercontent.com/zhuoyi0918/GlobalModeAlert/main/GlobalModeAlert.sgmodule
```

安装后确认模块已启用，且通知权限已打开（iOS 设置 → 通知 → Shadowrocket）。

## 参数

在模块里修改 `argument`，多个参数用 `&` 连接：

| 参数 | 默认 | 说明 |
|---|---|---|
| `interval` | `30` | 持续处于全局/直连时，重复提醒的间隔（分钟） |
| `global` | `1` | `0` = 不提醒全局模式 |
| `direct` | `1` | `0` = 不提醒直连模式 |

检测频率由 `cronexp` 控制，默认 `*/10 * * * *`（每 10 分钟）。

示例：只提醒全局、每小时提醒一次

```
argument=interval=60&global=1&direct=0
```

## 提醒逻辑

- 刚切到全局/直连 → 下一次检测时立即通知
- 一直不切回 → 每隔 `interval` 分钟重复提醒
- 切回配置模式 → 状态自动重置
- 两个探针都请求失败（断网等）→ 不做判断，不会误报

## 验证

安装后建议手动测一遍：小火箭 → 配置 → 脚本 → 找到「代理模式提醒」→ 手动运行。

1. 切到**全局** → 运行 → 应收到「全局代理还开着」
2. 切到**直连** → 运行 → 应收到「当前是直连模式」
3. 切回**配置** → 运行 → 不应有通知

## 已知限制

- 定时脚本只在 VPN 连接时运行，且受 iOS 后台调度影响，不保证准点。
- 如果「配置」模式下选中的节点出口在国内，探针 B 会返回 CN，被误判为直连模式。
- 依赖 `myip.ipip.net` 与 Cloudflare trace 两个公共接口，接口变动可能导致失效。
- 模块会把 `www.cloudflare.com` 强制走代理（只影响访问 Cloudflare 官网，不影响套 CF CDN 的节点连接）。
